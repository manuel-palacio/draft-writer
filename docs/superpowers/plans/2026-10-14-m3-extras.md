# Draft Writer M3 (Extras) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Part-of-speech syntax highlighting, and a library sidebar over one folder of notes.

**Architecture:**
- `DraftKit.SyntaxHighlighter` tags paragraphs with `NLTagger(.lexicalClass)`. Results are cached per
  paragraph text, and code ranges are skipped.
- The editor turns highlights and focus dimming into one set of TextKit 2 rendering colours, so dimmed
  words keep their hue.
- `DraftKit.Library` does the file work: scan, search, create, rename, trash. `DraftKit.FolderWatcher`
  wraps FSEvents. Both are testable against a temporary folder.
- The app keeps one `LibraryStore` (a security-scoped bookmark and the current tree), shown in a
  `NavigationSplitView` sidebar.

**Tech Stack:** NaturalLanguage (`NLTagger`, `NLLanguageRecognizer`, `NLTagger.requestAssets`), FSEvents
(CoreServices), security-scoped bookmarks, SwiftUI `NavigationSplitView` / `OutlineGroup` /
`openDocument`.

**Spec:** `docs/superpowers/specs/2026-10-14-draft-design.md` (section "M3 — Extras")

## Global Constraints

- All M1/M2 constraints still apply.
- Highlighting is off by default. The classes are noun, verb, adjective, adverb and conjunction, each
  toggleable. Colours have light and dark variants.
- Tagging covers only the visible paragraphs plus one screen of margin, cached by paragraph text.
  Code spans and blocks are never coloured.
- Language is detected per paragraph. If NaturalLanguage has no lexical-class model for it, the app
  calls `NLTagger.requestAssets` once and leaves the paragraph uncoloured until the model is there.
  Swedish has no model, so it stays uncoloured.
- Library: one root folder, kept as a security-scoped bookmark (new entitlement
  `com.apple.security.files.bookmarks.app-scope`). It shows `.md`, `.markdown` and `.txt` files and
  their folders, sorted by date modified (default) or name. Search matches names and contents,
  case-insensitive. Deleting a file moves it to the Trash after confirmation.

## Review Focus

1. **Paragraphs in unsupported languages** (Swedish) must stay uncoloured, not mis-tagged. Pinned in
   Task 1 (`swedishIsUncoloured`).
2. **Code inside prose** must never be coloured. Pinned in Task 1 (`skipsExcludedRanges`).
3. **Name collisions in the library** (Untitled.md exists, rename to an existing name) must not
   overwrite anything. Pinned in Task 3 (`untitledNumbering`, `renameRefusesExisting`).
4. **A stale bookmark** (folder moved or deleted) must show the "Choose folder…" prompt rather than an
   empty or broken sidebar. Pinned in Task 4 (`staleBookmarkClearsRoot`).
5. **Large libraries and big files during search** must not freeze the UI. The search runs off the main
   actor, and files over 5 MB are skipped for content search. Pinned in Task 3 (`searchSkipsHugeFiles`).

### Task 1: SyntaxHighlighter (DraftKit)

**Files:** Create `Sources/DraftKit/SyntaxHighlighter.swift` and `Tests/DraftKitTests/SyntaxHighlighterTests.swift`.

**Interfaces:**
- Produces:
  ```swift
  public enum LexicalClass: String, CaseIterable, Sendable { case noun, verb, adjective, adverb, conjunction }
  public struct Highlight: Hashable, Sendable { public let range: NSRange; public let lexicalClass: LexicalClass }
  public final class SyntaxHighlighter {            // not Sendable; used from the main actor
      public init()
      public func highlights(in text: String, range: NSRange, excluding: [NSRange]) -> [Highlight]
      public static func needsAssets(_ text: String) -> NLLanguage?   // dominant language lacking a model
  }
  ```
  `range` is widened to whole paragraphs. The cache key is the paragraph string, with relative ranges
  stored. The cache holds 2,000 entries at most and is cleared when full.

- [ ] **Step 1: Write the failing tests:**
  - `englishClasses`: `"The quick fox jumps quietly and happily."` gives `"fox"` → noun,
    `"jumps"` → verb, `"quick"` → adjective, `"quietly"` → adverb, `"and"` → conjunction.
  - `swedishIsUncoloured`: `"Det lilla huset står vid den blå sjön."` → `[]`.
  - `skipsExcludedRanges`: `"Use the `fast` path."` with the code range of `` `fast` `` excluded → no
    highlight intersects it.
  - `rangeIsWidenedToParagraph`: a range covering only "jumps" still returns highlights for the whole paragraph.
  - `rangesAreAbsolute`: for `"Intro.\n\nThe fox runs."` with a range in paragraph 2, `"fox"` is at its
    absolute UTF-16 location.
  - `cacheReturnsSameResult`: calling twice gives equal results (and the second call is ≤ the first in time).
- [ ] **Step 2: Run.** Expected: FAIL.
- [ ] **Step 3: Implement.** Split paragraphs with `NSString.enumerateSubstrings(in:options: .byParagraphs)`.
  `NLLanguageRecognizer.dominantLanguage` gives each paragraph's language. Only when
  `NLTagger.availableTagSchemes(for: .word, language:)` contains `.lexicalClass` do we tag, with
  `enumerateTags(... .omitWhitespace, .omitPunctuation, .joinNames)`, mapping
  `.noun/.verb/.adjective/.adverb/.conjunction`. Excluded ranges are filtered out afterwards.
- [ ] **Step 4: Run.** Expected: PASS. Commit: `feat: SyntaxHighlighter on NLTagger`.

### Task 2: Highlighting in the editor

**Files:** Modify `EditorView.swift` (rendering colours), `EditorSettings` (`syntaxHighlight: Bool`,
`highlightClasses: Set<LexicalClass>`), `Theme` (class colours), `Commands.swift` (View > Syntax
Highlight ⇧⌘H, and a submenu "Highlight" with one toggle per class), `DocumentWindow`.

**Interfaces:**
- Consumes: `SyntaxHighlighter`, `FocusController`, the code ranges from the last full styling pass.
- Produces: `EditorView(… highlightClasses: Set<LexicalClass>)`, where empty means off, and
  `Coordinator.applyRenderingColors()`, which replaces `applyFocus()` and does both jobs:
  1. remove the rendering foreground colour over the viewport-plus-margin range;
  2. add `Theme.dimmed` over the dimmed ranges;
  3. add the class colour for each highlight, at 30% alpha where it falls outside the bright range.
  It runs on selection change, text change (after the debounced full pass), scroll, and settings change.
  `Theme.color(for: LexicalClass) -> NSColor` uses these hues: noun #C2410C, verb #2563EB,
  adjective #A16207, adverb #9333EA, conjunction #059669, with lighter dark-mode variants.

- [ ] **Step 1: Write the failing hosted tests:**
  - `highlightsColourWords`: harness `"The quick fox jumps."` with all classes → the rendering colour at
    "fox" equals `Theme.color(for: .noun)`.
  - `focusKeepsHue`: `"One fox here. Two dogs there."`, sentence focus with the caret in sentence 2 →
    the colour at "fox" is the noun colour with alpha 0.3.
  - `codeIsNotHighlighted`: `"Use `fox` now."` → no rendering colour inside the backticks.
  - `disabledClassIsPlain`: classes `[.verb]` → no rendering colour at "fox".
  - The existing focus tests keep passing (`applyFocus` becomes an alias, or the tests call `applyRenderingColors`).
- [ ] **Step 2: Run.** Expected: FAIL. **Step 3: Implement. Step 4: Run** the whole hosted suite. Expected: PASS.
- [ ] **Step 5:** When `SyntaxHighlighter.needsAssets` returns a language, call
  `NLTagger.requestAssets(for:tagScheme:)` once per language per launch, and re-colour on success.
  Commit: `feat: part-of-speech highlighting`.

### Task 3: Library and FolderWatcher (DraftKit)

**Files:** Create `Sources/DraftKit/Library.swift`, `Sources/DraftKit/FolderWatcher.swift`, `Tests/DraftKitTests/LibraryTests.swift`.

**Interfaces:**
- Produces:
  ```swift
  public struct LibraryItem: Identifiable, Hashable, Sendable {
      public let url: URL; public let name: String; public let isFolder: Bool; public let modified: Date
      public var children: [LibraryItem]?            // nil for files
      public var id: URL { url }
  }
  public enum LibrarySort: String, CaseIterable, Sendable { case modified, name }
  public enum Library {
      public static let fileExtensions: Set<String> = ["md", "markdown", "txt"]
      public static let maxSearchFileSize = 5_000_000
      public static func scan(_ root: URL, sort: LibrarySort) throws -> [LibraryItem]
      public static func search(_ root: URL, query: String) throws -> [URL]   // names first, then contents
      public static func createUntitled(in folder: URL) throws -> URL
      public static func rename(_ url: URL, to newName: String) throws -> URL // keeps the extension when omitted
      public static func trash(_ url: URL) throws
  }
  public final class FolderWatcher { public init(_ url: URL, latency: TimeInterval = 0.3, onChange: @escaping @Sendable () -> Void); public func stop() }
  ```
  `scan` skips hidden files and packages. A folder appears only if it contains a matching file at some
  depth. Folders sort before files. Within each group, sorting is by modified date (newest first) or
  name (`localizedStandardCompare`).

- [ ] **Step 1: Write the failing tests** against a temporary folder:
  - `scanFindsMarkdownAndTxt`: `a.md`, `b.txt`, `c.png`, `.hidden.md`, `sub/d.md` and `empty/` → the
    names are `[sub, a.md, b.txt]` (with modified-date sort, after setting the dates explicitly), and
    `sub` has `d.md` as its child.
  - `sortByName`: `["b.md", "A.md", "c.md"]` → `A.md, b.md, c.md`.
  - `searchMatchesNameAndContent`: `apple.md` (content "x"), `notes.md` (content "An Apple a day") →
    query "apple" returns both, with `apple.md` first.
  - `searchSkipsHugeFiles`: a 6 MB file containing the query is not returned by the content match.
  - `untitledNumbering`: creating three times gives `Untitled.md`, `Untitled 2.md`, `Untitled 3.md`.
  - `renameKeepsExtension`: renaming `a.md` to "b" gives `b.md`.
  - `renameRefusesExisting`: renaming `a.md` to "b" when `b.md` exists throws, and both files are unchanged.
  - `trashRemovesFromFolder`: after `trash`, the file no longer exists at its URL.
  - `watcherFiresOnChange`: a watcher on the temporary folder, then writing a file, calls `onChange`
    within 5 s (awaited with a continuation and a timeout).
- [ ] **Step 2: Run.** Expected: FAIL. **Step 3: Implement.** Use `FileManager.contentsOfDirectory(at:
  includingPropertiesForKeys: [.isDirectoryKey, .contentModificationDateKey, .isPackageKey], options:
  .skipsHiddenFiles)`. Search reads contents with `String(contentsOf:)` using `TextDecoding` on the data.
  The watcher uses `FSEventStreamCreate` with `kFSEventStreamCreateFlagFileEvents` on a private
  dispatch queue. **Step 4: Run.** Expected: PASS. Commit: `feat: Library and FolderWatcher`.

### Task 4: Library sidebar in the app

**Files:** Create `DraftWriter/Library/LibraryStore.swift` and `DraftWriter/Library/LibrarySidebar.swift`;
create `DraftWriterTests/LibraryStoreTests.swift`. Modify `DocumentWindow` (`NavigationSplitView`),
`EditorSettings` (`showLibrary`, `librarySort`), `Commands.swift` (View > Show Library ⌘1, File > New
Note in Library ⌥⌘N), `project.yml` (the bookmarks entitlement).

**Interfaces:**
- Consumes: `Library`, `FolderWatcher`, `LibrarySort`.
- Produces:
  ```swift
  @MainActor @Observable final class LibraryStore {
      static let shared: LibraryStore
      init(defaults: UserDefaults)
      private(set) var root: URL?          // nil → "Choose folder…" prompt
      private(set) var items: [LibraryItem]
      var sort: LibrarySort
      var query: String                    // non-empty → searchResults
      private(set) var searchResults: [URL]
      func choose(_ folder: URL) throws    // stores bookmark, starts access, scans, watches
      func restore()                       // resolves bookmark; stale or unresolvable → root = nil, bookmark cleared
      func refresh() async
      func newNote(in folder: URL?) throws -> URL
      func rename(_ url: URL, to name: String) throws
      func trash(_ url: URL) throws
  }
  ```
- [ ] **Step 1: Write the failing hosted tests** (each with its own `UserDefaults(suiteName:)`):
  - `chooseScansFolder`: choose a temporary folder containing `a.md` → `items.map(\.name) == ["a.md"]`.
  - `restoreAfterRelaunch`: choose, make a new store on the same defaults, `restore()` → same root.
  - `staleBookmarkClearsRoot`: choose, delete the folder, new store, `restore()` → `root == nil`.
  - `queryRunsSearch`: set `query = "apple"` and await `refresh()` → `searchResults` contains the match.
- [ ] **Step 2: Run.** Expected: FAIL. **Step 3: Implement** the store. Search and scan run in
  `Task.detached` and are applied on the main actor. The watcher triggers `refresh()`.
- [ ] **Step 4: Sidebar UI.**
  - **No root:** a "Choose Folder…" button (`NSOpenPanel`, directories only).
  - **With a root:** a `List` with `OutlineGroup` over `items`, or a flat list of `searchResults` when
    `query` is set. It has a `.searchable` field and a sort picker.
  - **Rows:** a click opens the file with `@Environment(\.openDocument)`. The context menu has Rename
    (an alert with a text field) and Move to Trash (confirmation dialog).
  - **New note:** ⌥⌘N creates a note in the selected folder (or the root) and opens it.
  - **Layout:** `DocumentWindow` becomes `NavigationSplitView(columnVisibility:)` with the sidebar, and
    ⌘1 toggles `showLibrary`.
- [ ] **Step 5: Run** all suites. Expected: PASS. Update the README (features, ⌘1 / ⌥⌘N / ⇧⌘H, and
  that relative preview images now resolve for files inside the library folder). Commit:
  `feat: library sidebar`.
